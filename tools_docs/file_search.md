# file_search 工具使用指南

## 基本功能
file_search 是基于模糊匹配的文件路径搜索工具，当您知道部分文件路径但不确切知道文件位置时使用。

## 必要参数
- `query`: 要搜索的模糊文件名
- `explanation`: 解释为什么使用此工具以及它如何有助于目标

## 使用示例

```markdown
# 搜索配置文件
file_search(
  query="config",
  explanation="寻找项目中的配置文件"
)

# 搜索特定类型文件
file_search(
  query="component.tsx",
  explanation="查找React组件文件"
)
```

## 最佳实践
1. 当您知道文件名或部分路径但不确定完整位置时使用
2. 结果上限为10个匹配项，如需进一步筛选结果，请使用更具体的查询
3. 查询可以是文件名的一部分，扩展名，或路径的片段
4. 对于快速定位文件非常有用，特别是在大型代码库中
5. 结果将包括匹配的文件路径
